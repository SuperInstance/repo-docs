# negative-space-testing

## Intention
A Rust testing framework where you define what your system does NOT do — the pattern lives in the holes

## How It Works
negative-space-testing Test what your code doesn't do. A testing framework where you define forbidden behaviors — things your code must never produce — and the framework verifies the negative space. Traditional tests specify what code should do. This catches what slips through the cracks.
