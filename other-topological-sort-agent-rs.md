# topological-sort-agent-rs

## Intention
Advanced topological sorting with parallel, priority-aware, and incremental algorithms

## How It Works
An **advanced topological sorting** library for Rust supporting Kahn's algorithm (BFS), priority-aware sorting, parallel level scheduling via Rayon, and incremental edge insertion without full re-sort. Detects cycles and reports them as ordered node sequences.

The README includes code examples and API documentation.

Key topics: topology, fleet orchestration, agent system

## What It's For
Coordinating fleets of AI agents across distributed systems.

## Who Would Use It
