# topology-lab

## Intention
Topology lab — experimental topological data analysis, persistent homology, and simplicial complexes

## How It Works
**Interactive topological data analysis in your browser — persistent homology, symplectic integrators, sheaf cohomology on I Ching hexagrams, and music tension curves, all running client-side via Rust → WASM.**

The README includes code examples and API documentation.

Key topics: topology, Hamiltonian/symplectic, conservation laws, music/audio, homology, simplicial complexes
