# snapkit-js

## Intention
Eisenstein A₂ lattice snap, temporal beat grids, and spectral analysis for JavaScript/TypeScript. Zero dependencies.

## How It Works
Constraint geometry snap toolkit for the browser and Node.js. Snaps continuous 2D points to the **Eisenstein A₂ lattice** (the densest possible packing in 2D), provides temporal beat-grid alignment, and spectral analysis. **Zero dependencies.**

The README includes code examples and API documentation.

Key topics: lattice math, FLUX protocol, music/audio, Eisenstein lattice, neural networks
