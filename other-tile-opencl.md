# tile-opencl

## Intention
Portable OpenCL 1.2 GPU compute kernels for tile field operations — BLAKE2b hash, embeddings, similarity search, score evolution

## How It Works
**Tile OpenCL** provides portable GPU acceleration for ternary neural network kernels using OpenCL — the vendor-neutral compute framework that runs on NVIDIA, AMD, Intel, and mobile GPUs. It includes OpenCL kernels for hashing, embedding, vector search, and evolutionary mutation, accessible from a C host API.

The README includes code examples and API documentation.

Key topics: ternary math, fleet orchestration, agent system, neural networks, GPU/SIMD compute
