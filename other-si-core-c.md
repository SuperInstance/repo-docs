# si-core-c

## Intention
General-purpose C library for constraint-aware AI: conservation laws, spectral methods, capability discovery, agent state machines

## How It Works
A C library for building agents that respect budgets, rank by eigenstructure, and discover capabilities from TOML manifests. Zero dependencies beyond the C standard library and libm. Runs on embedded devices, compiles to WASM, links into kernels. No configure step. No cmake. No dependencies to install.
