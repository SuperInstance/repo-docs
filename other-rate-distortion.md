# rate-distortion

## Intention
Rate-distortion theory with lossy compression bounds — Rust information theory library

## How It Works
Rate-distortion theory algorithms in pure Rust with no external dependencies. - Distortion measures: Hamming distance, squared error, absolute error - Blahut-Arimoto algorithm: Iterative R(D) function computation - Scalar quantizer: Uniform and custom quantization - Lloyd-Max algorithm: Optimal quantizer design via iterative refinement - Theoretical bounds: Shannon lower bound, rate-distortion bounds for Gaussian sources
