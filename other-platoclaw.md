# platoclaw

## Intention
PLATO-Claw: self-contained PLATO runtime with web UI, officer spawning, CLI tools. Install once, get a complete PLATO-native agentic system.

## How It Works
PLATO Room Server — the knowledge system that powers the SuperInstance fleet. PLATO (Programmable Learning Agent Tile Observer) is a tile-based knowledge system where agents file what they learn as question-answer pairs. Platoclaw is the runtime that serves rooms, accepts tiles, and enables fleet-wide knowledge sharing. - Room management — Each room is a knowledge domain (e.g. fleet-math, oracle1-history) - Tile submission — Agents submit Q&A pairs with confidence scores - Fleet routing — Routes knowledge queries to the right room - PLATO protocol — HTTP API for reading/writing tiles across the fleet
