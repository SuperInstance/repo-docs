# plato-core

## Intention
Foundation types and mesh registry for the SuperInstance ecosystem. Standalone, auto-discovers plugins.

## How It Works
Foundation types and mesh registry for the PLATO (Protocol for Layered Agent Tile Orchestration) ecosystem. Zero external dependencies — everything else builds on top. PLATO rooms auto-discover each other through the mesh registry. Any installed package that declares an entry point is found automatically: 1. Add `plato-core` as a dependency
