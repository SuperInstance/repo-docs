## How It Works
SuperInstance Fleet — Mathematical Verification Infrastructure A Rust proof-of-concept benchmarking framework that compares float-based cosine similarity search against constraint theory-based search using the PythagoreanManifold from constraint-theory-core. This project demonstrates that structured geometric constraints can achieve competitive retrieval quality at reduced memory cost. Proof vector search is a technique for retrieving mathematical proofs (or proof-like structures) from large vector databases by encoding them as high-dimensional vectors and performing nearest-neighbor queries. Traditional approaches rely on raw floating-point representations and brute-force cosine similarity, which incurs significant memory overhead — especially at scale.
