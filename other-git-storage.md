# git-storage

## Intention
**Git-backed state management for any web app — auto-commit, time-travel, branch-aware.**

## How It Works
Not documented in a dedicated section. See the README for details.

## What It's For
| Problem | Solution |
|---------|----------|
| State lost on crash | Every write is a persisted git commit |
| Can't undo changes | Time-travel to any commit, tag, or branch |
| No change history | `history()` returns every version of any file |
| Walled in to one framework | Pure Node — works with React, Vue, Svelte, CLI, bots |
| Complex setup | `GitStorage.init(dir)` — that's it |
| Dependency
