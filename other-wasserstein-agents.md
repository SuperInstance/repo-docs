# wasserstein-agents

## Intention
Wasserstein distance and optimal transport — Sinkhorn algorithm, agent distribution coordination, JKO gradient flow

## How It Works
Measure how different your agents are. Make them converge. The Wasserstein distance is the cost of turning one distribution into another — literally the price of moving the dirt.

The README includes code examples and API documentation.

Key topics: fleet orchestration, agent system, optimal transport, blockchain/consensus
