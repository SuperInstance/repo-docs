# fleet-keel

**URL:** https://github.com/SuperInstance/fleet-keel

## Intention
5-dimensional self-orientation system for fleet agents using only internal dynamics. Verified by 53 GPU experiments.

## How It Works
Rust crate for agent self-orientation without external reference frames. Agents determine their position and heading in a 5D space using only internal dynamics.

## What It's For
Self-organizing fleets without central coordination.

## Who Would Use It
Autonomous systems researchers.

## Language/Stack
Rust

## Status Assessment
Active — 53 GPU experiments cited.

## Honest Assessment
Real project — novel approach to self-orientation. The experimental verification adds credibility.
