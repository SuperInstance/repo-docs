## How It Works

to Use

1. Open `index.html` in any modern browser (no server required)
2. Type a description of your device, or click an example prompt
3. Click **Parse & Verify** — the system runs the full pipeline
4. Explore each step:
   - **Constraint Program** — see variables and constraints
   - **Verification** — AC-3 solver checks satisfiability
   - **Wiring Diagram** — SVG schematic of your device
   - **Simulation** — interactive slider shows relay logic
   - **Download** — get the ESP32 sketch and config
