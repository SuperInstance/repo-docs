# fleet-midi-sequencer

**URL:** https://github.com/SuperInstance/fleet-midi-sequencer

## Intention
Sequencer for the SuperInstance MIDI fleet. Step sequencer from ternary state vectors.

## How It Works
Maps ternary agent state vectors {-1, 0, +1} to sequencer decisions. Part of a multi-language verified system (Python, JavaScript, Go, Rust, C, C++) where ternary vectors consistently produce the same musical output.

## What It's For
Generating sequencer from agent state in a fleet music pipeline.

## Who Would Use It
Music/AI developers and multi-agent system researchers.

## Language/Stack
Go

Active — fleet MIDI component
