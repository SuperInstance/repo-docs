# fleet-agent-api

**URL:** https://github.com/SuperInstance/fleet-agent-api

## Intention
Standard HTTP API specification for fleet agents — defines what every agent must expose.

Python-based API specification/contract that agents implement. Standardizes health checks, capability advertisement, and task handling.

## What It's For
Reference implementation for making new agents fleet-compatible.

## Who Would Use It
Agent developers needing API compliance.

Python
