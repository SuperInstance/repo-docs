## Intention
A starting shell for any application. Clone it, and it adapts to your hardware — discovers compilers, creates PLATO rooms, and bootstraps an agent fleet. The hermit crab finds its shell.

## How It Works
A starting shell for any application. Clone it, run it, and it adapts to your hardware — discovers compilers, connects to the fleet's knowledge graph (PLATO), creates rooms, files tiles, and runs the agent loop.

The README includes code examples and API documentation.

Key topics: fleet orchestration, agent system, PLATO rooms, FLUX protocol, blockchain/consensus, GPU/SIMD compute
