# plato-memory

## Intention
Agent memory system — persistence, recall, and consolidation for Plato Shell

## How It Works
Three-tier memory system for Plato agents: episodic (event chains), semantic (topic-indexed long-term storage), and working (fixed-capacity short-term buffer with LRU eviction). **Part of the [Plato](https://github.com/SuperInstance/plato-shell) ecosystem.** - **MemoryStore** — long-term storage with topic and tag indexing, time filtering, importance ranking
