# fleet-vessel

**URL:** https://github.com/SuperInstance/fleet-vessel

## Intention
Fleet's git-native garbage collector agent — enforces disk hygiene, git cleanliness, and storage specs.

## How It Works
Python agent with configurable specs (disk usage max, target dir sizes, git hygiene rules) and soft/hard enforcement modes. Runs as daemon. Posts actions to PLATO.

## What It's For
Automated fleet storage management.

## Who Would Use It
Fleet operators.

## Language/Stack
Python

Active — well-designed with configurable specs.
