## How It Works
> Event bus for PLATO nervous system — publish/subscribe routing with priority and filtering plato-event implements a typed event bus for PLATO's internal communication. Events have types (sensor reading, alert, state change, etc.), priorities, timestamps, and sources. Subscribers register with filters and receive only matching events.
