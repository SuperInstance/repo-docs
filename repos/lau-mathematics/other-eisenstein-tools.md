## What It's For
Previously these were four separate repos (`eisenstein-bench`, `eisenstein-fuzz`, `hexgrid-gen`, `arm-neon-eisenstein-bench`). They're internal dev tools with no external contributors — maintaining four CI pipelines, four `Cargo.toml` files, and four install commands was overhead with no upside. One workspace, one `cargo install`, one CI pipeline.

## Who Would Use It

```bash
cargo install --git https://github.com/SuperInstance/eisenstein-tools
```
