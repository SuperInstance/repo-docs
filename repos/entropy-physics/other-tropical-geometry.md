# tropical-geometry

## Intention
Tropical geometry for neural network analysis: max-plus algebra, tropical polynomials, and ReLU network correspondence

## How It Works
Tropical geometry replaces + with max and × with +. ReLU networks ARE tropical. This crate gives you the tools to see it.

The README includes code examples and API documentation.

Key topics: tropical algebra, neural networks
