# plato-shell

## Intention
Plato Shell — the agent runtime environment. Command execution, context management, and module loading.

## How It Works
Compose all Plato modules (puppeteer, manus, vision, sonar, correlator, tick, fleet) into a single MUD-like text-based world an agent can navigate and interact with. The central hub of the Plato ecosystem. **Part of [SuperInstance OpenConstruct](https://github.com/SuperInstance/OpenConstruct).** - **MUD-like rooms** — every module surface (desktop, devices, knowledge, fleet) is a navigable room

## What It's For
Part of the PLATO ecosystem. Plato Shell — the agent runtime environment. Command execution, context management, and module loading.

## Who Would Use It
