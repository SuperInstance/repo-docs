# plato-health

## Intention
Health check system for PLATO rooms — uptime, response times, error rates

## How It Works
> Health check system for PLATO rooms — uptime tracking, response times, error rates, and fleet status plato-health provides a complete health checking system for PLATO rooms. It tracks individual room health, aggregates fleet-wide status, computes uptime percentages, and measures mean time between failures. Each health check captures response time, error count, and check count. Health isn't binary. A room that responds in 50ms with 0 errors is healthy. A room responding in 2s with 5% errors ...
