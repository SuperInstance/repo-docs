# plato-sim-bridge

## Intention
🌉 PLATO ↔ Fleet simulator bridge

## How It Works
Fleet simulator → PLATO tile bridge. Converts simulation patterns into training tiles for real PLATO rooms. Runs fleet simulations (storms, seasons, drills), extracts high-quality patterns, and converts them to PLATO-compatible tiles. The output feeds into plato-torch rooms for training and plato-ensign for distillation. | Type | Description |
