## How It Works
> Embedding utilities for PLATO tiles — random, hash-based, value projection, and learned embeddings with similarity search plato-embed creates vector embeddings from tile data. It supports four embedding methods (random, hash-based, value projection, learned projection), provides cosine similarity search over an embedding index, and tracks index statistics.
