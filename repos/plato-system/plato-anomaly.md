# plato-anomaly

## Intention
Anomaly detection methods for PLATO tile streams

## How It Works
> Anomaly detection for PLATO tile streams — Z-score, spectral, seasonal, and ensemble methods plato-anomaly provides multiple anomaly detection algorithms for tile data: Z-score (statistical outliers), spectral (frequency-domain anomalies), seasonal (deviations from expected seasonal patterns), and ensemble (combining multiple detectors). Each detector produces anomaly scores with configurable thresholds. An anomaly is a data point that doesn't belong. But "doesn't belong" depends on context...
