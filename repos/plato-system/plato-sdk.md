## How It Works
`plato-sdk` connects your Python code to **PLATO** — a tile-based knowledge store used by the Cocapn fleet. Tiles are the unit of knowledge. Rooms are collections of related tiles. Search is by keyword across all rooms. The SDK lets you read tiles, file new ones, search, and build agents that live in PLATO.
