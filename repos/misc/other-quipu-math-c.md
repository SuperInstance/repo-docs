# quipu-math-c

## Intention

## How It Works
Incan knotted cord mathematics in C — encode, decode, and compute with quipu numbers. quipu-math-c implements the Incan quipu number system in C. Encode decimal numbers as knot sequences, decode them back, compute checksums, build cord trees, perform arithmetic, and serialize/deserialize quipu data. Use it for educational tools, novel encodings, or embedded systems that need cultural math. See quipu-math (PyPI) for full cultural background. Quipu encode decimal numbers as knotted cords — a tactile positional number system.
