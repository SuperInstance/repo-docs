# python-agent-shell

## Intention
Minimal Python shell for fleet agents with PLATO integration and fleet-coordinate access

## How It Works
Interactive Python REPL for SuperInstance fleet agents. A minimal, import-ready shell that gives agents PLATO integration, fleet-coordinate access, and constraint theory tools through a REPL you can pipe into any agent runtime. Point any agent at this shell and it gets a live REPL with fleet utilities pre-loaded. No config. No setup. Just clone, install, and the agent starts talking.
