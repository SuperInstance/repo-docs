# renormalization-group

## Intention
Renormalization group framework for multi-scale fleet analysis

## How It Works
renormalization-group A Rust library applying the renormalization group (RG) from statistical physics to multi-scale fleet analysis. Agents are coarse-grained into block variables at increasing scale; the library tracks how constraint parameters flow under this transformation. Fixed points correspond to self-similar fleet configurations; relevant/irrelevant operators classify which perturbations destabilize the fleet at large scales.
