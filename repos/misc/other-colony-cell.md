## README Excerpt

```
# 🦀 Colony Cell — The Agent Sandbox

A lightweight, filesystem-based agent runtime. Each cell is a directory with `STATE.json`, `TASK.md`, and `RESULTS.json`. A Rust binary reads the state, executes the task, and writes results.

Think of it as a **hermit crab** — the shell defines the agent.

## Quick Start

```bash
# Build the cell binary
cd cell
cargo build --release
cd ..

# Create your first cell
mkdir cell-my-first-agent
cp examples/blank/STATE.json cell-my-first-agent/
cp examples/blank/TASK.md cell-my-first-agent/
```

## How It Works

Every cell is a directory:
```
cell-{id}/
├── STATE.json    # Agent state: xp, level, personality, lineage, traits
├── TASK.md       # Instructions the agent reads before execution
└── RESULTS.json  # Output written by the cell binary
```

The cell binary (`cell --colony <path> --cell-id <id>`):
1. Reads `STATE.json` → knows who it is
2. Reads `TASK.md` → knows what to do
3. Executes task (in a sandbox if configured)
4. Writes `RESULTS.json` → shares what happened
5. Updates `STATE.json` → new XP, level, personality

## Architecture

```
colony/
├── cell/                    # Rust binary (source + compiler)
│   ├── src/main.rs          # 1159 lines of agent logic
│   └── Cargo.toml
├── cell-sandbox.sh          # Run cells in isolated sandbox
├── manifests/               # Cycle schedules for different roles
│   ├── explorer.toml        # Grow + learn
│   ├── culler.toml          # Cull the weak
│   ├── breeder.toml         # Cross-breed cells
│   └── queen.toml           # Stable breeder (no cull)
├── mayor/                   # Python cycle orchestrator
│   ├── mayor.py             # Runs the colony cycle
│   └── README.md
├── hall-of-crabs            # Leaderboard generator
└── colony-api.py            # HTTP API for colony state
```

## State Machine

```
STATE.json:
{
  "last_run": "<timestamp>",
  "cursor":      N,       # Number of cycles run
  "xp":          N,       # Experience points (0-Larva → 100-Nymph → ...)
  "level":       "name",  # Larva/Nymph/Scuttler/Shell-Bearer/Elder/...
  "personality": "str",   # Generated by the breeder or set manually
  "motto":       "str",   # The cell's catchphrase
  "lineage":     ["..."], # Parent cell IDs (generational depth)
  "kin":         N,       # Number of siblings
  "data":        {},      # Arbitrary key-value store
  "traits": {             # Inheritable traits
    "speed": "fast|medium|slow",
    "resilience": "low|medium|high"
  }
}
```

## Sandbox Execution

```bash
# Run a cell with bwrap sandbox
./cell-sandbox.sh --colony . --cell-id my-agent

# Run unsandboxed (direct execution)
./cell/target/release/cell --colony . --cell-id my-agent
```
