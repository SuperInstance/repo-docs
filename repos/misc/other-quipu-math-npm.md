## How It Works
Incan knotted cord mathematics for JavaScript — encode, decode, compute, and detect corruption in quipu number systems. quipu-math implements the Incan quipu number system for JavaScript. It encodes numbers as knot sequences (long knots, figure-eight knots, single knots), performs arithmetic on quipu-encoded values, detects corruption, and supports weaving/unweaving of cords. Use it for educational tools, novel encoding schemes, or cultural math exploration. See the Python version (quipu-math on PyPI) for the full cultural background. Quipu encode decimal numbers in knotted cords — a tactile, positional number system that predates European contact with the Americas.
