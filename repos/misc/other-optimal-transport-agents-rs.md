## Intention

## How It Works
optimal-transport-agents Wasserstein distance and optimal transport between agent distributions. Rust library for computing how much "work" it takes to reshape one agent distribution into another. Implements the Sinkhorn algorithm for entropic regularized transport, Jordan-Kinderlehrer-Otto (JKO) gradient flows for distribution evolution, Fréchet barycenters for distribution averaging, and Earth Mover's Distance for direct computation.
