# style-dna

## Intention
Musical DNA extraction, analysis, and style morphing system

## How It Works
Extract a composer's irreducible musical fingerprint from MIDI corpora, compare styles mathematically, and morph music toward target styles. Every composer has a DNA signature — topological, dynamical, and statistical invariants that survive across their entire corpus.

The README includes code examples and API documentation.

Key topics: topology, lattice math, FLUX protocol, music/audio, Eisenstein lattice, neural networks

Music theory, audio processing, or harmonic analysis.
