## How It Works
Fleet command center for the SuperInstance Live Paradigm architecture. This workspace orchestrates a real-time voice-to-MIDI pipeline: browser mic → OpenSMILE voice features → Ghost Track prediction → cue scheduling → 16 ternary fleet-midi agents → Piper TTS voice output.
