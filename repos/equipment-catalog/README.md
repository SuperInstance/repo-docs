# Equipment Catalog — Index

**Total repos: 14**

Multi-agent orchestration "equipment" — modular TypeScript/Ruby/PHP components for consensus, coordination, memory hierarchy, and self-improvement in agent swarms. These are the pre-built components that agent systems can plug in for specific capabilities.

## Category Overview

The Equipment catalog treats agent infrastructure as composable hardware-like components. Each piece of "equipment" handles a specific concern:

### Components by Function

#### Consensus & Decision Making
- **Equipment-Consensus-Engine** — Multi-agent deliberation with Pathos/Logos/Ethos weighting. Decisions are evaluated across emotional, logical, and ethical dimensions
- **Equipment-Consensus-Engine-PHP** — PHP implementation
- **Equipment-Consensus-Engine-Ruby** — Ruby implementation

#### Swarm Coordination
- **Equipment-Swarm-Coordinator** — Orchestrating multiple agents in origin-centric networks with asymmetric knowledge distribution. Agents only receive knowledge necessary for their tasks. 411-line README — the most documented component
- **Equipment-Swarm-Coordinator-Ruby** — Ruby implementation

#### Memory & Context
- **Equipment-Memory-Hierarchy** — Tiered memory system for agents (working → short-term → long-term)
- **Equipment-Context-Handoff** — Context transfer between agents during task delegation

#### Monitoring & Scaling
- **Equipment-Monitoring-Dashboard** — Real-time monitoring of agent fleet health
- **Equipment-Hardware-Scaler** — Dynamic hardware scaling based on agent demand

#### Intelligence & Learning
- **Equipment-CellLogic-Distiller** — Distilling complex logic into cell-level operations
- **Equipment-Teacher-Student** — Teacher-student knowledge transfer framework
- **Equipment-Self-Improvement** — Self-improvement loop for agent capability growth

#### Routing & Escalation
- **Equipment-Escalation-Router** — Route tasks to higher-tier agents when complexity exceeds thresholds
- **Equipment-NLP-Explainer** — Natural language explanations of agent decisions

### Key Interconnections

- The **Swarm-Coordinator** is the flagship component — comprehensive API, 411-line documentation, npm published (`@superinstance/equipment-swarm-coordinator`)
- **Consensus-Engine** implements a novel Pathos/Logos/Ethos decision framework — connecting to the Hodge decomposition work in sheaf-topology
- The polyglot approach (TypeScript + PHP + Ruby) mirrors the Grand Pattern polyglot strategy
- **Memory-Hierarchy** connects to the exocortex-memory persistent storage layer
- **Self-Improvement** and **Teacher-Student** relate to the active-inference cognitive framework
- Components are designed to be plug-and-play within the broader SuperInstance agent runtime
