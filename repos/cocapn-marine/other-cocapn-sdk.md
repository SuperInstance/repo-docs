# cocapn-sdk

## Intention

Software Development Kit for the cocapn ecosystem. Provides one API key for accessing any AI model.

## How It Works

The cocapn SDK offers:
- Unified API for multiple AI models
- Single API key authentication
- Model-agnostic interface
- Integration with cocapn agent infrastructure

## What It's For

Building applications and agents that need flexible access to different AI models through a consistent interface.

## Who Would Use It

Developers building on the cocapn ecosystem who need multi-model AI access.

## Language / Stack

Likely Python or JavaScript/TypeScript.
