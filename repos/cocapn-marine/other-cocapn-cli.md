# cocapn-cli

## Intention

Command-line interface for the cocapn fleet ecosystem. Provides terminal formatting and fleet interaction tools.

## How It Works

The cocapn CLI provides:
- Terminal-based fleet management
- Agent interaction commands
- Fleet status monitoring
- Terminal formatting and output

## What It's For

Managing and interacting with cocapn fleets from the command line.
