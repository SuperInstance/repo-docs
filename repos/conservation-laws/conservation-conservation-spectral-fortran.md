# conservation-spectral-fortran

## Summary
Fortran 2008+ with LAPACK.

## Intention
Port the Conservation Spectral SDK to fortran, demonstrating spectral graph analysis in any language while revealing paradigm-specific insights.

## How It Works
Implements the same pipeline: build tension graph, construct Laplacian (L = D - A), eigendecomposition, compute conservation ratio CR = lambda_2/lambda_n, detect anomalies. Each language highlights different paradigm strengths.

## What It's For
- Spectral graph analysis in fortran

## Who Would Use It
- Developers working in fortran
- Researchers comparing language paradigms for spectral computation
