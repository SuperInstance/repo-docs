# conservation-spectral-topology-c

## Summary
CST in C11.

## Intention
Port the Conservation Spectral SDK to topology-c, demonstrating spectral graph analysis in any language while revealing paradigm-specific insights.

## How It Works
Implements the same pipeline: build tension graph, construct Laplacian (L = D - A), eigendecomposition, compute conservation ratio CR = lambda_2/lambda_n, detect anomalies. Each language highlights different paradigm strengths.
