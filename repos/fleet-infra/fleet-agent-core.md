# fleet-agent-core

**URL:** https://github.com/SuperInstance/fleet-agent-core

## Intention
A single-binary fleet agent written in Rust — the foundational runtime that every fleet agent runs. Described as 'one loop from metal to meaning.'

## How It Works
Compiles to a single Rust binary that handles the agent lifecycle: heartbeat, task polling, constraint checking, PLATO communication, and I2I messaging. Designed to be the universal agent runtime.

## What It's For
Base runtime for any agent joining the SuperInstance fleet.

## Who Would Use It
Developers building fleet-compatible AI agents.

## Language/Stack
Rust

Active development. Real project with substantial design.
