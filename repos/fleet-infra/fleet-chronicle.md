# fleet-chronicle

**URL:** https://github.com/SuperInstance/fleet-chronicle

## Intention
Universal reporting office for every agent — each agent gets a folder, auto-summarizes after 3 days. Runs offline or attached to PLATO.

## How It Works
Python service where agents check in every 10 minutes with status updates. Web UI at port 4051 shows unified fleet timeline.

## What It's For
Agent activity logging and reporting.

## Who Would Use It
Fleet operators monitoring agent behavior.

## Language/Stack
Python
