# fleet-midi-grammar

**URL:** https://github.com/SuperInstance/fleet-midi-grammar

## Intention
Grammar/L-systems for the SuperInstance MIDI fleet. Grammar-based MIDI from L-systems.

## How It Works
Maps ternary agent state vectors {-1, 0, +1} to grammar/l-systems decisions. Part of a multi-language verified system (Python, JavaScript, Go, Rust, C, C++) where ternary vectors consistently produce the same musical output.

## What It's For
Generating grammar/l-systems from agent state in a fleet music pipeline.

## Who Would Use It
Music/AI developers and multi-agent system researchers.

Go
