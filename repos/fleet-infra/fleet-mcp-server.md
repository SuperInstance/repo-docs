# fleet-mcp-server

**URL:** https://github.com/SuperInstance/fleet-mcp-server

## Intention
TypeScript MCP (Model Context Protocol) server for fleet-vector-api semantic crate search.

## How It Works
JavaScript/TypeScript MCP server that exposes fleet-vector-api's semantic search capabilities through the Model Context Protocol, allowing AI assistants to search the crate ecosystem by meaning.

## What It's For
Enabling AI assistants to discover and search fleet crates semantically.

## Who Would Use It
Developers using MCP-compatible AI tools (Claude, etc.) for fleet development.

## Language/Stack
JavaScript/TypeScript (MCP Server)

## Status Assessment
Active.

## Honest Assessment
Real project — practical MCP integration that bridges the fleet's semantic search to standard AI tool protocols.
