# fleet-coordinate-js

**URL:** https://github.com/SuperInstance/fleet-coordinate-js

## Intention
Pure TypeScript port of fleet-coordinate math — Laman rigidity, H¹, ZHC, Pythagorean48. No WASM, no native deps.

## How It Works
~800 lines of TypeScript implementing the same geometric math as the Rust version. Runs anywhere JS runs.

## What It's For
Fleet coordinate math in browser/Node.js.

## Who Would Use It
JavaScript developers needing fleet math.

## Language/Stack
TypeScript
