# agent-forge

## Intention

Universal git-agent framework for building and orchestrating agents across repositories.

## How It Works

Agent Forge provides:
- Git-native agent development
- Repository-based agent lifecycle
- Fleet orchestration tools
- Integration with cocapn and PLATO

## What It's For

Building, deploying, and managing git-based agents that live and work across repositories.

## Who Would Use It

Developers building repo-first agents and fleet coordinators.
