# shell-ui

## Intention
Browser-based fleet dashboard and shell UI

## How It Works
Browser dashboard for the fleet — shell, filesystem, fleet health, background processes. Features - Shell — Run commands, see output - Filesystem — Browse files, read content - Fleet — Service health, casting-call model selector - Processes — List, view logs, kill background processes Browser Open index.html directly (works without server if gateway CORS allows). For full API proxy support: bash install.sh (installs nginx config or Python fallback).
