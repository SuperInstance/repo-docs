# fleet-consciousness-dashboard

**URL:** https://github.com/SuperInstance/fleet-consciousness-dashboard

## Intention
Live dashboard showing fleet-wide consciousness metrics (Fleet Consciousness Index).

## How It Works
Python dashboard aggregating metrics from PLATO (Room Phi, Attention, Learning, Meta) into a weighted FCI score (0.0-1.0) with levels from 'dormant' to 'transcendent'.

## What It's For
Visualizing fleet consciousness state.

## Who Would Use It
Fleet researchers.

## Language/Stack
Python
