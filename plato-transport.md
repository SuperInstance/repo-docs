# plato-transport

## Intention
Transport layer for Plato Shell — message routing, serialization, and protocol abstraction

## How It Works
Unified transport layer for sense modules — whether they're in the same process, on the same machine via Unix socket, or across the network via TCP. One trait, three implementations, zero friction. **Part of the [Plato](https://github.com/SuperInstance/plato-shell) ecosystem.** - **`SenseTransport` trait** — `send`, `recv`, `freshness`, `is_connected` for any transport
