# counterpoint-engine-rs

## Summary
Rust species counterpoint engine.

## Intention
Model species counterpoint rules as constraint satisfaction problems, enabling computational generation and verification of counterpoint.

## How It Works
Implemented in Rust. See README for API details.
Zero external dependencies.

## What It's For
- Computational music composition
- Music theory education

## Who Would Use It
- Computational musicologists and music theorists
- Graph theory researchers
- Multi-agent system engineers
- Developers needing zero-dependency spectral graph libraries

## Language/Stack
- **Primary language:** Rust

**Functional with tests.**

Clean, minimal, zero-dependency. First species rules well-implemented. Good reference implementation.
