## Intention
**Reinforcement Learning for Frozen Models**

## How It Works
**Reinforcement Learning for Frozen Models**

frozen-model-rl provides reinforcement learning methods that work with frozen model weights, optimizing behavior by learning constraint weights instead.

## What It's For
- ✅ **Zero model updates**: Keep models frozen, learn policies instead
- ✅ **Fast inference**: <1ms for bandit methods
- ✅ **Online learning**: Continually improves from conversations
- ✅ **Production-ready**: Monitoring, error handling, fallbacks
