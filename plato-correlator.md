# plato-correlator

## Intention
Event correlation engine for Plato Shell — pattern detection across agent interactions

## How It Works
Fuse shadow events from multiple sense modules (vision, sonar, motion) into unified assessments with severity classification. When two sensors agree, the confidence goes up. When they disagree, the correlator flags it. **Part of the [Plato](https://github.com/SuperInstance/plato-shell) ecosystem.** - **Temporal windowing** — correlate events within a configurable time window (default 500ms)
