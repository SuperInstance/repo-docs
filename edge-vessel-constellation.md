# vessel-constellation

## Summary
Vessels as N-body gravitational system.

## Intention
Vessels are agent containers — separating intelligence (agent) from runtime (vessel).

## How It Works
Implemented in Rust.

## What It's For
- Supporting the fleet ecosystem

## Who Would Use It
- SuperInstance ecosystem developers
- Edge/embedded engineers

## Language/Stack
- **Primary language:** Rust

## Status Assessment
**Early stage or stub.**

## Honest Assessment
Fleet vessels as N-body system is mathematically elegant. Whether this models real fleet dynamics is debatable.
