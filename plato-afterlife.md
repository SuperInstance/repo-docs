# plato-afterlife

## Intention

## How It Works
Ghost tile afterlife — dead agents live on through decaying knowledge tiles. When an agent is decommissioned, its knowledge shouldn't die. Plato Afterlife preserves agent tiles with a decay function — tiles gradually lose confidence unless reinforced by living agents. - **Ghost Tiles** — Preserve decommissioned agent knowledge
