# lau-kahler-agents

## Intention
**Kähler geometry for agents — where Riemannian, symplectic, and complex geometry unify.** A Rust library implementing the core structures of Kähler geometry: complex structures (`J`), Hermitian forms

## How It Works
README covers: Table of Contents, What This Does, Key Idea, Install, Quick Start, Build and verify a Kähler structure, Kähler potential and Fubini–Study metric, Hodge diamond for a Calabi–Yau 3-fold. Built as a Rust crate (cargo).
