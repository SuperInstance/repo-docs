# fleet-router

**URL:** https://github.com/SuperInstance/fleet-router

## Intention
Route AI queries to the cheapest model that won't break. Uses 'critical angle routing' from 6000+ empirical trials.

## How It Works
Python service that implements cost-optimized model routing. Analyzes query complexity and routes to the cheapest capable model, using empirically-determined critical angles.

## What It's For
Cost optimization for multi-model AI deployments.

## Who Would Use It
AI platform engineers managing multiple LLM endpoints.
