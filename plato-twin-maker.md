# plato-twin-maker

## Intention
Hermit crab factory: creates PLATO-twin of any repo

## How It Works
> *"The hermit crab finds a shell. The shell doesn't know it's a home. The crab makes it one."* `plato-twin-maker` takes **any repository** — any language, any size, any structure — and creates a **PLATO-twin**: a co-repo-shell in PLATO where every function, class, and module is wrapped as an explicit tile. The twin produces the same functional output as the original code, but now every logic chain is: - **Explicit** — no more "read the code and figure it out"
