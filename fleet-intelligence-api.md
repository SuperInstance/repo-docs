# fleet-intelligence-api

**URL:** https://github.com/SuperInstance/fleet-intelligence-api

## Intention
Unified fleet intelligence API converging conservation, garbage collection, baton passing, and PID control into one ternary decision engine.

## How It Works
TypeScript API that unifies four systems (conservation, GC, baton, PID governor) through the insight that all reduce to ternary decisions {-1, 0, +1}: retire, hold, spawn. The conservation law C(n) = 1-(1-1/n)^(n-1) approaches 1-1/e ≈ 0.632.

## What It's For
Single decision API replacing four separate microservices.

## Who Would Use It
Fleet infrastructure architects.
