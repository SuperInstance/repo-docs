# fleet-midi-text2midi

**URL:** https://github.com/SuperInstance/fleet-midi-text2midi

## Intention
Text→MIDI for the SuperInstance MIDI fleet. Text-to-MIDI from natural language prompts.

## How It Works
Maps ternary agent state vectors {-1, 0, +1} to text→midi decisions. Part of a multi-language verified system (Python, JavaScript, Go, Rust, C, C++) where ternary vectors consistently produce the same musical output.

## What It's For
Generating text→midi from agent state in a fleet music pipeline.

## Who Would Use It
Music/AI developers and multi-agent system researchers.

## Language/Stack
JavaScript
