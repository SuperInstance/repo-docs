# reallog-agent

## Intention
Vision/Fitness Turbo-Shell for cocapn domain

## How It Works
A small Python client for logging text descriptions of camera scenes to a PLATO tile server and querying them back with keyword matching. Each logged scene becomes one tile in the reallog-ai room. This package handles no images, video, or camera hardware — the caller supplies the description as a string.
