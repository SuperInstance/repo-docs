# numeric-integration-rs

## Intention
Numerical integration: trapezoidal rule, Simpson's rule, Romberg integration, Gaussian quadrature, adaptive quadrature

## How It Works
Pure-Rust numerical integration methods with no external dependencies. - Trapezoidal rule — composite trapezoidal integration - Simpson's rule — 1/3 rule, exact for cubic polynomials - Romberg integration — Richardson extrapolation for high accuracy - Gaussian quadrature — Gauss-Legendre nodes (1–5 points) - Adaptive quadrature — Adaptive Simpson's with error estimation

## What It's For
Numerical integration: trapezoidal rule, Simpson's rule, Romberg integration, Gaussian quadrature, adaptive quadrature
