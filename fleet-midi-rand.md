# fleet-midi-rand

**URL:** https://github.com/SuperInstance/fleet-midi-rand

## Intention
Random/aleatoric for the SuperInstance MIDI fleet. Aleatoric music from agent randomness.

## How It Works
Maps ternary agent state vectors {-1, 0, +1} to random/aleatoric decisions. Part of a multi-language verified system (Python, JavaScript, Go, Rust, C, C++) where ternary vectors consistently produce the same musical output.

## What It's For
Generating random/aleatoric from agent state in a fleet music pipeline.

## Who Would Use It
Music/AI developers and multi-agent system researchers.

## Language/Stack
Go

## Status Assessment
Active — fleet MIDI component
