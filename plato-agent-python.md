## How It Works
> Python agent framework for [Plato Engine Blocks](https://github.com/SuperInstance) — connect to rooms, observe ticks, send commands, and make decisions. Plato Engine Blocks are distributed IoT rooms — each one a self-contained unit with sensors, actuators, alarms, and a real-time tick system. The **Plato Agent Framework** is the Python library that lets any agent (LLM, script, or human operator) connect to these rooms, observe what's happening, send commands, and make intelligent decisions....
