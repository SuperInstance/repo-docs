# plato-sandbox

## Intention
Sandboxed execution environment for Plato Shell — isolated agent runtime with resource limits

## How It Works
Run agent-generated code in an isolated sandbox with resource limits, policy enforcement, and monitoring. Currently simulated (tracks resources without OS-level isolation), with architecture ready for real process-based sandboxing. **Part of the [Plato](https://github.com/SuperInstance/plato-shell) ecosystem.** - **Configurable resource limits** — max memory (MB), max CPU time (ms), max output (bytes)
