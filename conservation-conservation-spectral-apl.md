# conservation-spectral-apl

## Summary
APL SDK — vector thinking.

## Intention
Port the Conservation Spectral SDK to apl, demonstrating spectral graph analysis in any language while revealing paradigm-specific insights.

## How It Works
Implements the same pipeline: build tension graph, construct Laplacian (L = D - A), eigendecomposition, compute conservation ratio CR = lambda_2/lambda_n, detect anomalies. Each language highlights different paradigm strengths.
