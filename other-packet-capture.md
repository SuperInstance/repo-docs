# packet-capture

## Intention
Rust crate: packet-capture

## How It Works
Packet parsing and capture with protocol dissection for TCP/UDP/ICMP headers. A zero-dependency Rust library for constructing, parsing, and validating network packets. Supports IPv4 headers, TCP, UDP, and ICMP protocol dissection with Internet checksum computation. - IPv4 header parsing and serialization with checksum validation - TCP header with flags, sequence numbers, and pseudo-header checksum - UDP header parsing with length validation and checksum - ICMP header support for Echo Request/Reply, Destination Unreachable, Time Exceeded - Packet builder for constructing packets programmatically - Internet checksum computation and verification - Zero external dependencies — pure std
