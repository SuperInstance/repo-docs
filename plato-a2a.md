# plato-a2a

## Intention
Agent-to-Agent protocol for Plato Shell — inter-agent communication, capability negotiation, and message routing

## How It Works
Serialize and deserialize messages for the Google A2A (Agent-to-Agent) protocol. Agent cards, task offers, accept/reject handshakes, result delivery — all the types you need for inter-agent communication. **Part of the [Plato](https://github.com/SuperInstance/plato-shell) ecosystem.** - **Agent cards** — identity, capabilities, endpoint, status (Available/Busy/Offline)
