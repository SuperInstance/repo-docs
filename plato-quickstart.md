## How It Works
**Bootstrap a Plato room in 30 seconds** — sensor configurations, alarm rules, and fleet manifests for real-time physical-space monitoring. `plato-quickstart` is a CLI tool that scaffolds the JSON configuration files needed to run a "room" in the Plato monitoring system. Each room defines sensors (temperature, RPM, pressure), actuators (alarms, limiters), and alarm rules with cooldown semantics. A fleet manifest ties multiple rooms together under a coordinator.
