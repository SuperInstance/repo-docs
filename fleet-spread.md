# fleet-spread

**URL:** https://github.com/SuperInstance/fleet-spread

## Intention
Fleet graph analysis with 'library gate architecture' — select THE ONE specialist that matches instead of running all five.

## How It Works
Rust crate that analyzes fleet graph topology to find the optimal single agent for a task, rather than broadcasting to all agents. Uses constraint-aware graph traversal.

## What It's For
Efficient agent selection without broadcast overhead.

## Who Would Use It
Fleet orchestration developers.

## Language/Stack
Rust

## Status Assessment
Active.

## Honest Assessment
Real project — interesting 'selection vs. broadcast' optimization with legitimate graph theory.
