## How It Works
A **GPU-accelerated vector search** library using PyTorch tensors for brute-force exact nearest-neighbor search. Automatically selects between CPU and GPU based on database size, with FP16 support for 2× capacity and sub-millisecond latency for databases under 10K vectors.
